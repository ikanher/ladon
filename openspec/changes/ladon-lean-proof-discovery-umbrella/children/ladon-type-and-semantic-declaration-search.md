# `ladon-type-and-semantic-declaration-search`

Finds declarations by elaborated type patterns and semantic signature/name evidence, with Lean checking the shortlisted candidates.

- Dependencies: completed index/scope capability and existing Lean helper supervision.
- Enables: premise-difference routing.
- Excludes: lexical similarity as proof compatibility.
- Exit: exact, reducible, coercion, negative, bounded, and no-match fixtures pass.
