# `ladon-goal-capture-and-application-probes`

Captures a source-position goal and local context, then checks candidate applications in isolated temporary examples.

- Dependencies: concrete unresolved-field evidence and existing Lean process supervision.
- Enables: checked local-context evidence in the proof frontier.
- Excludes: target-repository writes or an editor-only execution path.
- Exit: context fidelity, stale-location, diagnostic, cleanup, isolation, and timeout fixtures pass.
