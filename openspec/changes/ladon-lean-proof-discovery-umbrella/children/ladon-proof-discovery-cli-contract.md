# `ladon-proof-discovery-cli-contract`

Makes every new proof-discovery operation an ordinary, versioned Ladon CLI surface with compact text and canonical JSON.

- Dependencies: existing installed CLI execution authority.
- Enables: consistent public interfaces for all other children.
- Excludes: a model-only command, hidden defaults, or a second CLI authority.
- Exit: installed help, parsing, streams, exits, docs, and the maintained skill agree.
