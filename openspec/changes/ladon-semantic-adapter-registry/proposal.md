## Why

Symmetry, representation transports, measurability bridges, and other one-step adapters are useful only when their direction, side conditions, provenance, and Lean verification remain explicit.

## What Changes

- Add a versioned built-in registry and validated repository JSON extension.
- Resolve registry declarations through the semantic index and verify every proposed adapter application in Lean.
- Rank adapter routes deterministically and expose rule identity, direction, cost, residual premises, and authority.

## Capabilities

### New Capabilities

- `ladon-semantic-adapter-registry`: Inspectable one-step semantic adapters with Lean-verified applications and explicit side conditions.

### Modified Capabilities

## Impact

Adds registry models/schema, repository configuration validation, verifier integration, ranking fields, fixtures, docs, and policy-boundary tests.
