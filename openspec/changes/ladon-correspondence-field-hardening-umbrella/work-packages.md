# Work packages and acceptance gates

Implement these packages within this umbrella. Splitting one into a child later
must replace its detailed tasks with exact child/evidence links, not duplicate
ownership. No package is implemented by creation of these planning documents.

| Package | Depends on | Consuming result | Exit evidence |
|---|---|---|---|
| A — typed interpretation lowering | Frozen baseline | The original rational interval/bound survives real Lean elaboration | Public CLI rejects or correctly types the old ambiguous encoding; corrected Real, intentional Nat division, Rat and Int controls replay; actual subject exposed to reviewer |
| B — local-context transport | Frozen baseline; integrate with A | Recorded A₀/A₁ application supplies original connecting goals without source rename | Actual formal context and all required supply/transfer links checked, with shadowing/escaped-witness negatives |
| C — measured execution | A/B correctness baselines | Faster repeated preparation and bounded compact public outputs | Same semantic/trust results, request mutation negatives, paired phase timings, defined performance target met |
| D — continuation and finalization | Frozen baseline | A `continue` decision leads to further recorded work or a genuine stopping condition | Public CLI/driver receipts for continue, checkpoint, completion, budget, blocker, cancellation, and stale stop records |
| E — integrated qualification | A–D | One public workflow uses all new behavior while preserving authority | Frozen regression suite, real-source replay, independent final audit, parent tests and strict validation |

## A/B regression population

Freeze portable examples and exact original field subjects before production
edits. Include positive Real fractions, intentional truncated Nat division,
negative Int numerals, Rat arithmetic, nested overloaded applications, an
operator/type mismatch, and wrong-but-provable encoding. Check literal
elaboration, not just whether a supplied proof closes. Separate typing probes
from the substantive premise and conclusion obligations.

For contexts include subscripts, primes/quoted names, repeated display names,
dependent local types within the admitted profile, local values, two branches,
and a witness that must not escape. Preserve the exact original A₀/A₁ source
selection and module context; no basename rename or invented hypothesis counts
as acceptance. Record other unsupported constructs honestly.

## C measurement gate

Freeze the public command, selected goal population, supplied terms, source and
compiled import identities, cache/setup state, hardware/concurrency, and process
limits. Record a baseline from the semantically corrected A/B implementation
before optimizing it; a pre-fix failure is not a faster successful baseline.
Use the cone, corrected numeric, and adjacent-derivative workloads, with
portable controls for negative outcomes. No concurrent full rebuild during
paired comparisons. Default three paired trials per workload; predeclare any
necessary departure before collecting comparison results.

Report phase and end-to-end wall time, process count, peak-memory measurement
scope, serialized bytes, distinct subjects, checks by kind, and every failure.
Required target: at least 30% lower median cone-check wall time, with at most 10%
median regression on either other supported workload. Every previously required
freshness, replay and axiom check remains effective. Missing this target leaves
the performance task open; report a bounded negative experiment and revise the
route, never discard an authority check to meet it.

## D deterministic continuation gate

Drive an unfinished v3 plan at a simulated 57.65 minutes of a 90-minute budget.
`finalize` must refuse ordinary termination and return the pending queue. Save a
checkpoint, perform a real recorded next action, and verify the start/deadline
did not move. Also test elapsed budget, explicit attributed user stop, all-work
blocked with evidence, one blocked item plus actionable work, forbidden reference
checks with visible omissions, and a changed plan invalidating a prior receipt.
No test waits 90 minutes or treats idle waiting as meaningful continuation.

## E qualification scope

Run one short end-to-end portable workflow through source interpretation,
actual extraction, generated links, fresh checks, sanitized independent review,
ingestion, checkpoint and finalization. Revisit the three known field subjects
using immutable original evidence plus new result directories. The actual
Navier–Stokes math is development material, not a new independent discovery run.

Require focused lowering/context tests, real Lean negative/positive controls,
source-goal/checking/freshness consumers, native validators/projections, v1/v2/v3
investigation and CLI consumers, bounded-output/resource checks, relevant strict
quality commands, and independent final integration review. Do not silently skip
required Lean tests when toolchains are unavailable. Obtain no new dependency,
whole-paper build, target-error web search, model API, publication, or commit as
an incidental acceptance step.

Completion means the declared tooling behavior and measured consuming gates
passed. It does not mean the reported paper issue was detected or that this
workflow outperforms an ordinary auditor. Deciding on another blind run belongs
after this umbrella's evidence is reviewed.
