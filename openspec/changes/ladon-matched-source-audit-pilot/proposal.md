# Proposal

## Why

The recent source-consistency recipe qualification showed that Ladon can check supplied mathematical obligations, but it did not test whether the workflow helps readers find useful source discrepancies or saves review effort. A small matched pilot is needed to decide whether further semantic-audit machinery is worth integrating.

## What Changes

- Prepare and, after the preregistration gate is satisfied, run a bounded comparison of the same model using ordinary Lean and the same audit recipes, with Ladon access as the measured difference.
- Freeze fresh source/Lean units, prompts, budgets, answer isolation, adjudication, and cost accounting before either arm starts.
- Produce paired reports, independent adjudications, and a decision report; a negative or inconclusive result completes the pilot without establishing Ladon’s general effectiveness.
- Stop before launch if fresh comparable material, independent adjudication, or the predeclared practical success threshold cannot be secured.

## Capabilities

### New Capabilities

None. This is an evaluation protocol; it does not add product behavior.

### Modified Capabilities

None.

## Impact

The packet covers a bounded development evaluation using existing Ladon commands and ordinary Lean. It does not authorize production integration, changes to the frozen pitfall baseline, or claims about general mathematical reliability. Candidate source materials may come from `../lean/matrix-factorization/latex/natural-language`, but previously exposed or diagnosed material is ineligible for discovery scoring.
