# `ladon-theorem-capsule-replay`

Validates and rebuilds a capsule in a fresh root with the original checkout
unavailable, then compares exact theorem, structural dependency, and trust evidence.

- Dependencies: completed `ladon-theorem-capsule-materialization`, the process
  supervisor, exact Lean helper protocol, and installed CLI output contract.
- Enables: the bounded `verified` capsule status and the combined extract-and-verify
  product flow.
- Excludes: an independent proof checker, global minimality, axiom-freedom beyond
  recorded trust facts, implicit network policy, offline vendoring, or universal
  OS-level hermeticity.
- Exit: portable fixtures demonstrate checkout-independent success and distinguish
  content, environment, dependency, resource, Lean, identity, trust, and isolation
  failures in canonical redacted receipts.
