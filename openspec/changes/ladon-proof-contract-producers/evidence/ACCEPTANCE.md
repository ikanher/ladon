# Bounded producer acceptance

The producer child is implemented for the declared natural-scale fragment. The
[source gate](SOURCE-GATE.json) extracted six real Lean statement types and
retained two unsupported domains in 11.93 seconds, with a measured 1.91 GiB peak
under the 12 GiB cap. Its [complete observations](SOURCE-GATE-OBSERVATIONS.json)
bind source bytes, environment, helper protocol v2, declaration ranges, feature
origins and process receipts. Axiom fixtures test statement observation only.
Historical pre-hardening and pre-identity receipts remain separate files.

Attributed prose capture preserves independent alternative readings and original
source hashes. Formal capture accepts no authored feature override. The ordinary
`investigation contract produce`, `inspect`, `expand` and `fidelity-record`
operations expose these paths. See [the supported matrix and examples](../../../../docs/PROOF_CONTRACTS.md).
Statement coverage survives an actually unavailable axiom body; targeted requests
retain their exact application and obligation and leave overall provider coverage
incomplete. A pinned Lean control checks subtype/guarded equivalence and a concrete
counterexample to membership erasure. Independent fidelity review reuses ordinary
investigation observations, retaining the frozen snapshot's attribution.

[Validation](VALIDATION.json) distinguishes the focused 85-test milestone, the
current 35-case canonical helper-refactor replay, actual body-expansion control,
and the compatibility run's one failure followed by its exact regression fix.
Whole-repository static quality has zero issues and Ruff passes. This child does
not claim a full integrated umbrella test pass. All 130 assertions in the five
helper-refactored files retain identical ASTs; frozen revisions and original bytes
were preserved before the root applied that refactor.

The [independent initial review](INDEPENDENT-REVIEW-initial.md) established stdout
impersonation and feature-origin ambiguity. Both were corrected and
[independently retested](INDEPENDENT-REVIEW-followup.md): the helper writes a
separate bounded result after the frontend returns, and recognition carries exact
right-scale node paths. Rehashed authored features cannot replace the retained
observed statement during inspection. A later small root change reuses the
existing finite resource validator; five new invalid-bound tests went red to
green. Source hashes and that review's scope are explicit in validation evidence.

This accepts bounded engineering behavior. Source fidelity remains
`attributed-unreviewed`, checker authority is `none`, and mathematical falsity is
`not-established`. Snapshot inspection establishes freshness and consistency,
not authenticated observations. Lean frontend IO retains caller privileges;
the result file is not a malicious-code sandbox. Unsupported domains, scales,
quantifiers and custom arithmetic/order/numeral instances remain residuals.
No unfamiliar-paper detection benefit or general analytic extraction is claimed.
