## Why the interfaces do not connect yet

`_contract_propagation_inputs.read_contracts` requires the profile digest from
`proof_contract_rules`, whose meaning is `norm-scale-v1` over nonnegative Nat
scales. The admitted Real envelopes instead carry `real-bound-v1`, exact typed
expressions, and checked source-predicate/canonical-scalar interpretations.
Changing the digest or discarding those expressions is not a semantic bridge.

The source review also found that `produce_prose_contract` calls the original
`validate_contract`, which accepts only `norm-scale-v1`. Thus the existing prose
contract producer does not author Real-native counterparts. This is a source
inspection result, not an additional executed public CLI case.

The separate Real prefix, coefficient, chain and transfer operations remain
useful. They check specified edges or a fixed ordered chain. They do not perform
the general AND/OR frontier evaluation required by the chosen integration route.
Conditional transfer composition retains both source transfer statements as
assumptions; its success cannot stand in for their proofs or a prose-norm bridge.
These restrictions are deliberate current contracts, not an unsoundness finding.

## Next implementation decision

Keep the source-pair gate and evaluation populations unchanged. The next useful
design input is one provenance-established original pair with a frozen prose
interpretation, including domain, norm, derivative convention, guards and
coefficient scope. For a Real-bound pair, two interfaces then need explicit
acceptance contracts:

1. An attributed Real prose reading with source origins and independent fidelity
   review, preserving alternatives before matching. Authoring a reading must not
   grant formal admission or claim a norm equivalence.
2. A profile-specific frontier path that consumes admitted Real predicates and
   checked edges with exact source contexts, preserving ordered premises and
   conditional transfer assumptions. Unsupported context transports and prose-norm
   bridges must remain named obligations.

Use the selected pair to determine the smallest required behavior. Do not begin
a broad Real evaluator, relax source independence, increase the Nat binder cap,
or search for an easier synthetic success to mark Task 2.1 complete. The current
runtime freeze has no automatic new exception from this negative feasibility
result. The existing independently reviewed producer and propagation child
evidence remains valid for its original bounded scopes.
