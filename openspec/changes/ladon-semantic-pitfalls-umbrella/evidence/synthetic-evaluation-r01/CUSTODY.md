# Construction custody

This is N.2m evaluation preparation, not an audit run or a scored result. The
existing N.2b recipe was frozen before these cases were authored. `INPUTS.json`
binds that freeze and the unchanged local original proof capsule.

## Roles

- The author/custodian constructs candidate passages and retains interpretations,
  roles, source diffs, witnesses, and construction history privately.
- A separate reviewer challenges the mathematical labels, source context, and
  answer-free projections. Rejected versions remain construction history.
- The root integrates aggregate decisions and verifies file identities without
  reading the answers or changing the frozen workflow.
- Future audit arms receive one variant in a fresh context. They must not receive
  this evidence directory, the private packet, other variants, or development
  answers. Their execution requires the separate N.2c registration.

The private construction directory is
`.codex/state/pitfalls-n2m-custody-r01/`. Do not recursively copy that directory
into an audit workspace. Deliver only the explicitly enumerated files for the
selected unit, together with the common original Lean capsule and the common
recipe specified in the later registration. Preserve the per-unit content hashes.

## Boundaries

Case preparation uses local retained sources. The live matrix-factorization
checkout is not a build or audit dependency. Original Lean modules and capsule
metadata remain unchanged. Any oracle helpers belong outside the delivered
import closure. The development repository contains exposed oracle material and
is not an evaluation input.

The two construction roles know the answers and cannot later act as blind
auditors. The root knows the intended aggregate composition and original source;
it is not a blind auditor either. These filesystem and role rules are procedural
separation, not an operating-system access-control boundary. A future launcher
must enforce the declared input projection and record any exposure incident.

Acceptance requires mathematical support for each label. A failed proof search
is insufficient. Source-reviewed mathematics, compiled original Lean, and new
formal counterexample certificates are distinct kinds of evidence; none should
be described as another. One source cluster with related variants is not five
independent papers and cannot establish natural-error discovery.
