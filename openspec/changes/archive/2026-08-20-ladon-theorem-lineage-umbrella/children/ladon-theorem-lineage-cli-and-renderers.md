# `ladon-theorem-lineage-cli-and-renderers`

Adds the ordinary `ladon theorem lineage THEOREM` interface with database-first
refresh and bounded text/JSON views.

- Dependencies: DB ingestion, SQL queries, and projection exit classes.
- Enables: end-to-end repository calibration and maintained guidance.
- Excludes: caller-specific behavior, implicit lexical fallback, and DOT v1.
- Exit: installed help, refresh, warm-hit, parity, stream, exit, signal, resource,
  cap, and existing theorem-command regression gates pass.
