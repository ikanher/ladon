# `ladon-type-directed-declaration-search`

Combines scoped SQLite shortlist buckets with one Lean verification batch and deterministic ranking.

- Starts after: name/freshness, schema, semantic build, and verifier.
- Enables: differences, constructor coverage, and planning.
- Excludes: unverified structural matches in default results.
- Exit: contract, authority, scope, query-plan, and latency gates pass.
