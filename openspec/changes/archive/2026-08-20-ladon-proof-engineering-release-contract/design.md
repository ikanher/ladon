## Context

The final packet integrates all public schemas and commands and determines whether older overlapping proof-discovery concerns have equivalent replacement evidence.

## Goals / Non-Goals

**Goals:** pinned portable fixture, installed command parity, six acceptance scenarios, relative performance gates, documentation/skill synchronization, and legacy reconciliation.

**Non-Goals:** making sibling repositories mandatory test dependencies or claiming semantic commands are safe for untrusted repositories.

## Decisions

1. Portable Lean fixtures are authoritative; Matrix-Factorization calibration is optional, fingerprinted observational evidence.
2. Installed text and JSON must be semantically equivalent and every expensive bound must appear in JSON.
3. Documentation examples run as contract tests and use ordinary human/tool CLI commands only.
4. Legacy changes are marked superseded only when the ledger maps every concern to a passing new exit class.

## Risks / Trade-offs

- [Docs drift] → executable help/example/skill scans.
- [Host-dependent performance] → relative gates on the same host plus phase breakdowns.
- [Legacy reconciliation loses scope] → explicit concern-by-concern disposition ledger.
