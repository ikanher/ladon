# `ladon-analysis-inspection-surface`

Exposes canonical modules, declarations, imports, audits, options, resources, and
lexical proof-mechanism evidence through one ordinary installed CLI surface.

- Dependencies: the
  `ladon-report-coverage-and-snapshot-integrity#coverage-foundation` milestone,
  `ladon-declaration-and-audit-integrity`,
  `ladon-generated-family-candidate-detection`,
  `ladon-actionable-findings-workflow`, and the existing source-index/cache
  contracts.
- Enables: late-row lookup, complete human/script/editor/model navigation,
  producer review-registration rows, and ordinary action templates for
  report-owned regions without unbounded reports.
- Excludes: caller-specific commands, implicit Lean/Lake/VCS execution, semantic
  tactic dependency claims, or a second atlas/query engine.
- Exit: installed text/JSON inspection is deterministic, paginated, authority- and
  coverage-bearing, rejects stale indexes, invokes no target build by default,
  and does not synthesize complete review-region objects.
