# `ladon-proofir-query-access-paths`

Derives direct, partial, graph, triage, and foreign-key child access paths from every production ProofIR SQL shape.

- Starts after: baselines and schema rightsizing.
- Enables: coverage-sensitive integration and release.
- Excludes: changing ProofIR authority.
- Exit: populated dossier, triage, DAG, cascade, plan, latency, and byte-cost gates pass.
