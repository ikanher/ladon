# `ladon-signal-benchmark-harness`

Owns versioned portable labels and separate correctness, coverage, runtime,
memory, process, cache, schema, size, and determinism measurements through the
installed ordinary CLI.

- Dependencies: shared CLI/report contracts and the clean tracked-source
  baseline; final measurements wait for stabilized signal semantics, Lean
  runtime, and declaration fields.
- Enables: evidence-backed alpha promotion and release budgets.
- Excludes: model-quality scores, whole-report snapshots, and required sibling
  repository checkouts.
- Exit: portable positive/negative/boundary gates pass; live repositories are
  non-blocking drift evidence only.
