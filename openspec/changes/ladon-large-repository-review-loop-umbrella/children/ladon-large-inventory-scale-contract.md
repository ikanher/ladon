# `ladon-large-inventory-scale-contract`

Owns the portable large-project fixture, reusable source index, cold/warm
profiling, canonical report payload ownership, explicit report projections,
and compatibility migration away from duplicated alpha-v2 payload locations.

- Existing owners reused: report-v2 version dispatch/readers, benchmark process
  metrics, installed CLI serialization rules, and clean-checkout gates.
- Enables: bounded scope planning, resumable runsets, and practical installed
  report-set consumption.
- Excludes: new finding kinds, Lean helper semantics, automatic root choice,
  target-specific generated rules, and Matrix-Factorization as required CI
  input.
- Exit: a reviewed generated large-project fixture satisfies cold/warm time,
  RSS, output-size, determinism, invalidation, and single-payload-ownership
  budgets on the required Linux reference job across every supported Python
  minor; all current readers pass through the documented compatibility path.
