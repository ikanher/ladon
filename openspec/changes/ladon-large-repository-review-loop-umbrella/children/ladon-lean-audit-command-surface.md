# `ladon-lean-audit-command-surface`

Owns lexical/parser and optional elaborated rows for command-only `#check` and
`#print axioms` audit references, audit-facade classification, and bounded Lean
resource directives.

- Dependencies: explicit scope plans, calibrated ownership populations, and
  partial-run observability.
- Existing owners reused: declaration identities, source evidence,
  authority/provenance vocabularies, and optional elaborated extraction.
- Excludes: proof-truth claims, transitive axiom closure unless supplied by a
  separately authoritative Lean artifact, filename-only audit inference, or
  unconditional resource-budget findings.
- Exit: portable fixtures resolve positive audit references, exclude
  comment/string negatives, retain unresolved rows honestly, locate resource
  directives with literal scope/value, and never report an audit facade as the
  owner of referenced mathematics.
