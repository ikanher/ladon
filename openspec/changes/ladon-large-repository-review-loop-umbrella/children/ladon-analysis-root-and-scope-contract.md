# `ladon-analysis-root-and-scope-contract`

Owns non-executing scope preview and explicit owner, local import-closure,
namespace, multi-root, changed-set, and inventory population contracts.

- Dependencies: the source-index milestone from
  `ladon-large-inventory-scale-contract` and the existing CLI/report contracts.
- Enables: owner-relevant reports, bounded Lean requests, and runset planning.
- Excludes: mathematical relevance inference, implicit git commands, merged
  multi-root reports, proof-dependency closure, or hard-coded repository roots.
- Exit: portable multi-library fixtures resolve each scope deterministically,
  report exact selected/omitted/truncated populations and expected helper
  batches, and never label omitted modules as observed clean.
