# Frozen implementation contract

Root owns runtime/docs/OpenSpec and shared-state changes. Workers use read-only inspection or `.codex/scratch/loop-*` files. Four slots observed including root; two Luna-medium red workers, then an independent Luna-medium final auditor. No network, target math answers or production Quux imports needed. Reuse task board `/home/codex/projects/ladon/.codex/state/correspondence-discovery/swarm.sqlite3`, frontier loop.

Runtime API: `ladon.investigation.assess(plan: dict, root: Path, *, now: datetime | None = None) -> dict`; invalid inputs raise ValueError. Lazy entrypoint `ladon investigation init/status/next/finish`; JSON output by default. CLI main `ladon.investigation_cli.investigation_main(argv)` returns 0 for accepted operations, 2 for rejected finalization or invalid input. Init flags --text, --root, --output, --minutes (default90), --unit-lines (default80). Others --plan, --root, --limit (default8). Init refuses overwrite. Status/next read-only.

Plan: version1, startedAt UTC ISO, budgetSeconds positive integer; scope {path, sha256 rawhex, startLine, endLine}; units [{id,startLine,endLine,inventory:pending|done,note:string}]; claims [{id,unit,startLine,endLine,quote,state:captured|contract|reviewed|blocked,...}]. Unit ranges partition scope exactly; no gaps/overlaps. Claims stay inside named units and quote equals complete source lines joined with newline (no final newline). Unit inventory done requires nonempty note; pending units cannot hide claims. Claims require nonempty ids and source quotes; zero claims is allowed only with explicit inventory note for the unit.

Source contract required for contract/reviewed states: nonempty strings objects, assumptions, domains, quantifiers, conclusion, dependencies, neededImplication. Reviewed also requires formal {path,sha256,startLine,endLine,statement,contract:{same seven fields}} and judgment {statement:aligned|mismatch|unresolved, method:same|different|unresolved, evidence:string}. Formal statement equals bound source lines. All judgments attributed. Reviewed with unresolved statement OR method remains an actionable follow-up. Blocked requires blocker {kind,evidence,nextAction,unblockCondition} nonempty strings; residual remains unresolved. No comparison without required contract fields.

Next batch: pending units first, then captured claims (write-exact-contract), contract claims (compare-formal-contract), unresolved reviews (resolve-local-obligation), deterministic source order. Blocked claims visible separately. Before deadline and with pending work: status continue, mayFinalize false, finish exit2. No pending work but blockers: incomplete-blocked, mayFinalize true. Deadline exhausted with residuals: incomplete-budget, mayFinalize true, residuals visible. Otherwise recorded-work-complete, mayFinalize true. No mathematical-correctness result.

Bounds: plan4MiB; each source8MiB; distinct sources total128MiB; max4096 units/claims; output next limit1..100. Reject duplicate JSON keys, nonfinite values, booleans as numeric fields, future/naive timestamps, bad ids/ranges, stale digests/quotes, escaped paths/symlinks. Current read source must stay within explicit root. Missing/empty source and source changed after init reject. Root can author tests for all bounded-input cases before integration; frozen tests may not be weakened.

Acceptance is new actionable exact-contract work and honest stop behavior, not time spent waiting, a semantic detector, a heading inventory or an answered-target rediscovery. User cancellation overrides procedure and saves interrupted evidence. All prior pilot and first-report files remain unchanged.
