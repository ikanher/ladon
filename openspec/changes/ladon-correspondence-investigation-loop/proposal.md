# Proposal

## Why

The fresh full-exposition retest read broadly but compared only three local questions and stopped after fifteen minutes of a ninety-minute ceiling. The previous workflow exposes omissions but has no consuming operation that keeps actionable source contracts in the investigation queue.

## What Changes

- Add `ladon investigation init/status/next/finish` for an authored, revision-bound source-work plan. Generate bounded source units, expose missing inventory and exact contracts, and refuse premature finalization while useful work remains.
- Require exact source spans, local hypotheses/domains/quantifiers/conclusions/dependencies and attributed comparisons; retain blockers and budget-limited scope explicitly. Preserve original propositions and historical failed reports.
- Exercise the runtime with portable regression controls and a resumed early-stop state. Update the generic workflow and prepare a separate hint-free restart workspace.
- Stop after implementation, checks and independent review. This change does not claim fault detection, rerun the scored toy corpus or conduct an answer-informed purported blind test. See [acceptance](specs/correspondence-investigation-loop/spec.md).

## Capabilities

### New Capabilities

- `correspondence-investigation-loop`: source-scoped contract queues and honest investigation finalization. No existing canonical capability owns this workflow controller.

### Modified Capabilities

None. The previous correspondence-discovery change and closed result formats retain their historical authority.

## Impact

Ladon lightweight entrypoint, a dependency-free controller/CLI, focused tests, workflow documentation and packaged skill. No proof-IR schema changes, model service or Quux production dependency. The fresh retest inputs are an explicitly user-authorized external output; historical runs stay intact.
