# Generated source-leaf bridges

The new `check_planned_source_bridge(source_request, terms)` API checks one
version-two native source demand through an actual provider application slice,
existing correspondence goal generation, source-goal completion and independent
replay/trust checks. The serial source acceptance cases pass. The full relevant
regression gate passes all 888 tests across 136 files in 379.52 seconds.

The four channels are closed source-requirement supply, universal-Nat identity
mapping, representation typing, and conclusion transfer. The middle transfer
term has a concrete offset-two versus offset-zero type mismatch. The parent
term reports `Unknown identifier ThreeSteps.endpoint`. Missing terms are not
supplied automatically. All accepted completions have accepted independent
replay and trust checks. These outcomes establish checker behavior on known
constructed controls; unsuccessful terms do not establish mathematical falsity.

## Context and authority

The operation reconstructs the whole plan and fresh source observations rather
than accepting a prepared correspondence plan or caller-written goal. Every
goal retains the original reading/desired-plan digests, selected route occurrence,
exact native demand and its independently recomputable digest. All incoming
occurrences remain attached to that demand. A complete generated provider
adapter ends before the original parent declaration, with compiler guards
excluding both that declaration and the original source module. Its actual
scoped application slice is generated evidence, not an observation of the
original proof body.

This initial profile supports two explicit universal Nat binders, no proposition
assumptions, a named global coefficient, and identity domain/representation
transport. The domain proof establishes the generated identity maps on Nat;
the representation goal establishes typing. Neither certifies a nonidentity
semantic representation equivalence. Original prose fidelity remains attributed
and unreviewed. Whole-method authority remains none and mathematical falsity
not established.

The broader ordered-premise/domain/representation capability and missing-provider
dispatch remain open. This introduces no beam search, corpus admission, new
matrix baseline or Navier–Stokes retest. Detection benefit remains unmeasured.
