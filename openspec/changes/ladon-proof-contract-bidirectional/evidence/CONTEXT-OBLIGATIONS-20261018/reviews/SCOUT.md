# Context bridge scout (assignment 557)

Status: read-only architecture recommendation. Baseline: child `PROVIDER-EXPANSION-20261018/FINAL-RUNTIME.json` (488 entries, accepted separately). No code, Lean, tests, source workflow, or canonical edits performed; no dependencies proposed. Scratch only.

## Finding and recommended boundary

The smallest ordinary public path is a new bridge-specific operation alongside `check_planned_source_bridge`, implemented as an adapter that reconstructs a fresh source demand/selected route exactly as `prepare_bridge` does, extracts the provider application, then calls a refactored *scoped-obligations builder* in `correspondence_check`. Keep `prepare_correspondence` as-is for its current whole-slice behavior. Do not expose a caller-supplied prepared plan or list of goals as proof inputs. The public API takes only the closed native source request and ordered term attempts; it regenerates every subject.

The builder should accept the validated native interpretation batch/ref and the fresh source-bound application slice, an exact binder-identity object map, and an explicit transport profile. It returns an immutable plan whose identity commits to: interpretation artifact + source-map artifact refs, exact quote/source digest, source declaration/application/occurrence and slice ID, source-prefix digest, native demand/route/selected-reading digests, ordered telescope and premise occurrence IDs/digests, object map, transport profile, and all generated goal text/digests. Checkpoint boundaries revalidate those inputs and regenerate the plan before checking terms; a changed context, input artifact, prefix, selected application, goal, or term mapping rejects as stale/forged. Continue existing strict-prefix compiler guards and independent replay/trust checks.

## Obligation construction contract

Represent context as an ordered telescope plus ordered proposition premises, never a flattened caller-authored implication string. Lower telescope binders in order and allow a domain to reference only prior binder identities. Map each source premise occurrence to its own interpreted proposition, preserving occurrence number even when propositions are textually identical. Generate independent closed goals under exactly the telescope: (a) source-leaf/provider requirement; (b) one premise-supply goal per actual ordered premise occurrence; (c) domain transport; (d) representation transport; (e) conclusion transfer. Premise-supply goal proves the mapped proposition from the actual source-leaf provider and earlier declared context only; no missing premise is inserted as a local assumption. Conclusion transfer may consume only the individually checked premise receipts, never the disputed output or unfinished parent. Goal receipts remain route-local and unresolved until actual kernel checking and independent replay accept them.

For a `Fin (n + 1)` telescope, e.g. `∀ n : Nat, ∀ i : Fin (n+1), P n i`, the existing scoped formula lowerer already resolves earlier binder identities and preserves lexical order. New tests/checker work must establish that lowering/type elaboration succeeds and rejects forward references/escaped identities. This is within the current *formula* fragment if `Fin` is an ordinary Lean type name and the formula operators have supported nondependent signatures. It is not yet a general dependent function-signature/type-theory bridge.

For a nonidentity representation (e.g. source `X` mapped to formal `Y`), require explicit source-bound representation terms and separately generated goals for typing and every needed direction of transport/equivalence. A one-way map must not silently justify reverse conclusion transport. The current `object-map` `True` goal only checks declared typing; it must be replaced or retained strictly as a typing subgoal, with semantic map obligations explicit. No equivalence or inverse may be synthesized from type compatibility.

## Feasible example / present limitation

A useful first fixture is a source leaf with two ordered premises `h₀ : A n` and `h₁ : B n i`, a dependent `i : Fin (n+1)` binder, and conclusion `C n i`. The plan should expose premise-0, premise-1, domain, representation, and conclusion goals, bind them to the actual application occurrence and native interpretation/source owner, and reject an attempted conclusion term that assumes `C n i` or a proof term naming the parent endpoint. If the source leaf has no premise, this degenerates to the already demonstrated four-channel Nat fixture.

The current shipped path cannot do this example end-to-end: `_selected_offset` rejects all nonempty assumptions, `_validate_telescope` accepts only two universal `b0,b1` binders, `_formula` hardcodes Nat and identity map, and `bridge_goals` emits only source requirement + identity-Nat domain + object-map + conclusion. More fundamentally, `prepare_correspondence` currently conjoins assumptions into one implication and emits per-premise goals from that combined context; this does not yet represent proof dependency order or derive later assumptions from earlier checked premise receipts. Existing `check_correspondence` does safely re-extract the slice and rebuild the whole plan (`_rebuild_original_plan`), but that mechanism must be adapted to regenerate the new precise obligation bundle. Native interpretation validation proves exact quoted-span/source-map ownership and typed lowering, not semantic fidelity of the attributed statement.

## Rejected shortcuts / guarantees

- Never accept caller-prepared goals, modified plan rows, or arbitrary `assumptions`; rebuild from the exact native request and freshly validated batch.
- Never include the desired conclusion, missing premise, or parent declaration in staged source; use prefix digest plus positive/negative declaration guards already present in bridge supervision.
- Never turn failed search into falsity. Preserve unresolved obligations, unsupported dependent operator signatures, incomplete slices, resource stops, `attributed-unreviewed` interpretation fidelity, and checker authority `none`.
- Do not claim that a valid object-map type proves semantic representation equivalence, or that source-map ownership certifies prose truth.
