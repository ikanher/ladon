## Lean coverage boundary

The raw audit checks: (1) generic positive-region integral iff measurable-event DP bound; (2) a strictly-positive-density forward-loss pushforward/profile integral identity; (3) product concrete-PLD-pair equality with composed PLD family under independent product measure and density hypotheses; and (4) analytic Gaussian condition/event-form equivalences plus the restricted centered finite-Gaussian one-way event theorem described under S1. These signatures do not cover P1 existence/uniqueness, P2 arbitrary likelihood-law construction, P3 tail/smoothing/differentiation/reconstruction, or the Gaussian note's full G1/G2 identities and envelope. The checked `#print axioms` lines report only standard `propext`, `Classical.choice`, and `Quot.sound` for the three printed theorems; this is not evidence for the unqueried source claims.
