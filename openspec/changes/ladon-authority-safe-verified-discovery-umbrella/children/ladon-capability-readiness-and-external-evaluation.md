# `ladon-capability-readiness-and-external-evaluation`

Replaces feature-presence claims with measured capability readiness and held-out outcomes.

- **Owns:** readiness ladder; machine-readable evidence registry; preregistered goal/finding corpora; baseline adapters; separate outcome metrics; promotion/demotion rules; product-profile documentation.
- **Starts after:** verified discovery vertical slice exits and portable benchmark infrastructure is green.
- **Integration owners:** supported-feature generator, benchmarks, installed smokes, architecture calibration, docs/release evidence.
- **Enables:** an internal technical-alpha decision; it does not authorize public distribution.
- **Excludes:** mandatory CI dependence on live external repositories, one aggregate quality score, ranking changes made on held-out data, daemon/Rust/optional-layer expansion.
- **Exit:** experimental/contract-supported/externally-evaluated/release-qualified levels are generated from executable evidence; a frozen multi-repository corpus reports discovery and architecture outcomes separately against preregistered baselines; documentation reflects measured readiness.
