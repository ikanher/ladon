# `ladon-proof-discovery-correctness-repairs`

Repairs the three reproduced discovery failures before any new discovery feature work.

- **Owns:** exact candidate lookup; validated non-truncated type selection; unavailable/ambiguous explanation; `type-text` command and schema; scope enforcement; verified freshness; migration diagnostics; installed adversarial fixtures.
- **Starts after:** umbrella evidence capture and command-spelling decision.
- **Integration owners:** proof-search index/query, proof-difference, installed CLI, documentation, maintained skill.
- **Enables:** `ladon-authority-safe-release-gate` after its complete installed suite passes.
- **Excludes:** Lean unification, candidate batch checking, evidence-axis redesign, broad service extraction, ranking tuning.
- **Red evidence:** goal `True`, candidate `Demo.proof`, indexed type `True`; distinct repository/module/closure/external populations; verified freshness without generation evidence; ambiguous and truncated candidate rows.
- **Exit:** the old command fails with migration help; every accepted scope changes or proves its population; verified freshness exposes matching identities or stale status; explanation never compares a declaration name; isolated-wheel tests pass outside the checkout.
