## Why

JSON evidence queries are ahead of the ordinary text CLI, and the new semantics are not yet calibrated on real repositories. The product is useful only when humans and tools receive equivalent bounded results and the queries materially improve evidence completeness.

## What Changes

- Complete ordinary CLI syntax for theorem dossiers, artifact evidence, routes/trees, and repository triage.
- Render text and canonical JSON from the same versioned result dictionaries.
- Document refresh, bounds, authority, nonclaims, and project-local database behavior.
- Add portable end-to-end tests and fingerprinted Quux/Matrix-Factorization calibration.
- Update the authoritative Ladon skill after installed commands are verified.
