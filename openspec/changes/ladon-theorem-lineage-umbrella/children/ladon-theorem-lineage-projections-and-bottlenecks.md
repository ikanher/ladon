# `ladon-theorem-lineage-projections-and-bottlenecks`

Turns bounded SQL-selected DAGs into representative spines, collapse summaries,
bottlenecks, and reference-preserving tree unfoldings.

- Dependencies: stable bounded SQL result rows.
- Enables: readable text/JSON CLI output.
- Excludes: graph layout, proof importance scoring, and alternative-proof claims.
- Exit: projection identity, spine, bottleneck, shared-reference, cycle, cap, and
  nonclaim gates pass.
