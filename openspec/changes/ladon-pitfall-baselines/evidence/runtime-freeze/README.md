# Runtime custody

The original `runtime.json` is a preliminary tracked-file hash inventory and remains historical. The `runtime_custody.py` helper captures recoverable payload bytes and complete path/mode/digest inventories, including missing tracked runtime files and actual untracked runtime source files. `source-artifacts-v2.json` retains the complete selected source/compiled-artifact mapping and identifies generated/stale artifacts without source mappings.

Snapshot payloads live under the stable ignored local path `.codex/state/pitfall-runtime/bundles/`. Capture stdout supplies the manifest identity. A retained acceptance record outside the bundle must pin this identity; pass it explicitly with `--identity` to **every** accepted restore, verify, run or exec command. The adjacent `manifest.sha256` alone is a self-consistency convenience, not an independent trust anchor. A full bundle replacement with a rewritten sidecar must be rejected against the retained external identity.

The snapshot is an x86_64 Linux runtime image. It preserves the actual Python interpreter, stdlib and extension-library closure (Ladon declares no Python runtime dependencies), selected whole Lean toolchains, fixture/package source and build trees, required Git/shell utility bytes, and loader/library bytes. Development-only Python packages are excluded. File and directory symlink contents are materialized as regular files; direct file-symlink targets are recorded as provenance. The reconstructed tree is the declared executable representation, not a copy of the donor's symlink topology.

The launcher scrubs ambient environment values and provides fixed locale/timezone, snapshot-relative library/tool paths and fresh per-execution HOME/TMPDIR. CPython uses the saved loader. Lean runs through its own executable so `/proc/self/exe` points at the toolchain; the required host interpreter loader must have exactly the recorded and saved digest. This platform binding is checked before selected-profile execution. Commands must use the captured profile paths; ambient elan/uv and pip-installed Ladon are not runtime inputs.

Capture checks reconstruction headroom and bounds every compressed write to retain that reserve. Restore checks current destination capacity and uses a temporary extraction tree before publication. Integrity, inventory, mode, launcher and source/artifact checks precede execution. Final Task 1.1 acceptance also requires actual full-image reconstruction, import-origin and both Lean fixture checks; synthetic helper tests alone do not close it. Operational tactic/search policy and per-case input isolation remain Task 1.3.

Independent helper contract tests and root replay logs are retained under `verification/`. Engineering coordination uses `.codex/state/pitfall-runtime/board.sqlite3` (ultra-code board, scope `task:ladon-pitfall-runtime`). All dispatched workers for this frontier are explicitly Luna at medium reasoning. No baseline detection run is implied by custody checks.
