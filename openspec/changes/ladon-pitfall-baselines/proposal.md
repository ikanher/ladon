# Proposal

## Why

Existing regression checks cover several correspondence boundaries, but there is no measured suite spanning the actionable pitfalls in the supplied article. The legacy contract evaluation is fixed to a different 24/12 population and must not silently acquire new cases or claimed discovery credit.

## What Changes

- Freeze a local-checkout baseline and a 24-case development corpus: six pitfall families, each with two faults and two faithful controls, all with actual Lean counterparts.
- Score machine evidence from supplied interpretations separately from agent-authored source readings; retain unsupported cases, failed checks, and resource stops.
- Reuse compatible identity and report utilities; add a separately versioned evaluation profile without changing legacy registration counts.
- Provide a staged family-baseline unlock for the three implementation children, starting with feasibility, followed by the full validated scorer and matched 24-case before/after metrics.

Current review findings and the next implementation steps are owned by [tasks.md](tasks.md). Corpus acceptance must include source-to-goal semantic agreement, resolvable evidence references, subject/oracle separation, actual control coverage and verified operational import restrictions before measurement.

Detailed acceptance is in [the capability specification](specs/ladon-pitfall-regression-evaluation/spec.md). Success is evidence for the declared bounded behavior, with limitations visible to the caller.

## Capabilities

### New Capabilities

- `ladon-pitfall-regression-evaluation`: Frozen case populations, evidence-aware scoring, and matched pitfall development measurements.

### Modified Capabilities

None. Existing probe, identity, authority and coverage requirements remain in force; these additions do not reinterpret historical results.

## Impact

Evaluation utilities, portable Lean fixtures, case manifests and benchmark scripts. Runtime detection changes belong to sibling children. All cases inspired by the article are known development cases, not blind research-paper evidence.
